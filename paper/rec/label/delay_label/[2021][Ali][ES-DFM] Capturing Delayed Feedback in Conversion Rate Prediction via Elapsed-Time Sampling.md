# ES-DFM: Capturing Delayed Feedback in Conversion Rate Prediction via Elapsed-Time Sampling

**论文**：[arxiv 2012.03245](https://arxiv.org/abs/2012.03245)
**发表**：AAAI 2021
**机构**：阿里巴巴

---

## 核心问题

在线 CVR 预测需要持续训练以保持模型新鲜度，但转化标签存在随机延迟，导致大量**假负例（False Negative）**。

DFM 和 FNW 都存在一个根本缺陷：对"假负例"的处理依赖于等待时间 $e$ 这个超参数，但从未系统地建模等待时间本身带来的影响。

ES-DFM 明确提出这个 trade-off：

```
等待时间 e 短 → 数据新鲜，但假负例多（很多正例还没到）
等待时间 e 长 → 标签准确，但模型过时
```

---

## 核心思路：建模观察分布 vs 真实分布

设样本在观察时刻 $e$（距点击经过的时间）下，观察到的分布与真实分布的关系为：

$$q(y=1 \mid x) = p(y=1 \mid x) \cdot P(h \le e \mid x, y=1)$$

$$q(y=0 \mid x) = p(y=0 \mid x) + p(y=1 \mid x) \cdot P(h > e \mid x, y=1)$$

其中 $h$ 为转化延迟时间。第二项中的第二部分即为假负例：正例延迟未到。

**目标**：用重要性加权把观察分布校正回真实分布：

$$\mathcal{L} = \mathbb{E}_{q} \left[ \frac{p(y \mid x)}{q(y \mid x)} \cdot \ell(y, f_\theta(x)) \right]$$

**具体权重：**

| 样本类型 | 权重 |
|---|---|
| 正样本 | $1 + p_{dp}(x)$ |
| 负样本 | $(1 + p_{dp}(x)) \cdot p_{rn}(x)$ |

其中：
- $p_{dp}(x)$：该样本是延迟正例的概率（用辅助分类器估计）
- $p_{rn}(x)$：该样本是真负例的概率（用辅助分类器估计）

完整 loss：

$$\mathcal{L} = -\sum_{i} \left[ y_i (1+p_{dp}(x_i)) \log f_\theta(x_i) + (1-y_i)(1+p_{dp}(x_i)) p_{rn}(x_i) \log(1-f_\theta(x_i)) \right]$$

---

## 与前作的本质区别

| | DFM | FNW | ES-DFM |
|---|---|---|---|
| 对延迟分布的假设 | 指数分布（参数化） | 无 | 非参数，动态估计 |
| 等待时间 $e$ 的处理 | 在 loss 里隐式用到 | 固定阈值 | 显式建模，作为 trade-off 核心 |
| 实时更新 | ✓ | ✓ | ✓ |
| 标签到来后再训练 | ✓ | ✓ | ✓ |
| 对假负例的校正 | 通过分布假设 | 固定重要性加权 | 随 $e$ 动态变化的重要性加权 |

## 实验结果

**数据集**：
- Criteo：6000 万样本，60 天，CVR 0.23%
- Taobao：98 亿样本，14 天，CVR 3.27%

**评估协议**：流式训练，第 $t$ 小时训练 → 第 $t+1$ 小时测试

**离线结果**：
- Criteo：AUC 0.8402 vs FNW 的 0.8373
- Taobao：AUC 0.8895 vs FNW 的 0.8845

**在线 A/B**：AUC +0.3%，CVR +0.7%，GMV +1.8%

---

## 主要贡献

1. 首次将"等待时间 $e$"从工程超参数变为可显式建模和优化的变量
2. 通过非参数地估计经过时间分布 $p(e \mid x)$，动态调整假负例修正权重，不依赖指数分布强假设
3. 提出与工业流式训练对齐的严格评估协议

## 附录：生存分析背景

### 什么是生存分析

生存分析（Survival Analysis）原本是医学统计里的概念，研究"某个事件什么时候发生"。经典问题：

```
给一个病人，他在接受治疗后，还能活多久？
```

核心要建模的不只是"会不会发生"，而是**"什么时候发生"**。

**生存函数 $S(t)$**：

$$S(t) = P(T > t)$$

即到时刻 $t$ 为止，事件还没发生的概率。

**右删失（Right Censoring）**：研究结束时有些病人还活着，只知道他活过了观察期，但不知道最终什么时候死。这类样本不能丢弃，也不能当做"永远不死"处理。

### 映射到 Delay Feedback 问题

| 医学 | 广告 |
|---|---|
| 病人 | 一次点击 |
| 事件 = 死亡 | 事件 = 转化 |
| 生存时间 $T$ | 转化延迟 $h$ |
| 研究结束时还活着 | 观察截止时还没转化 |
| **右删失样本** | **假负例** |

假负例问题本质上就是右删失问题：观察时刻 $e$ 时样本还没转化，只知道 $h > e$，不能直接当负例处理。

### DFM 如何用生存分析处理假负例

DFM 假设转化延迟 $h \sim \text{Exp}(\lambda(x))$，对应生存函数：

$$S(t) = P(h > t) = e^{-\lambda(x)t}$$

对一个在时刻 $e$ 还没转化的样本，其 likelihood 为：

$$\underbrace{(1 - p(y=1 \mid x))}_{\text{真负例}} + \underbrace{p(y=1 \mid x) \cdot e^{-\lambda(x)e}}_{\text{假负例，延迟未到}}$$

这是生存分析里处理右删失样本的标准做法——不丢弃，而是用已知信息（活过了 $e$）构造偏似然。

ES-DFM 继承了这一思想，但不依赖指数分布假设，改为用辅助分类器非参数地估计 $P(h > e \mid x)$。
